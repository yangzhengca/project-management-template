# Initiatives — Deep Dive

## Strategic Alignment Model

The full system works only when alignment is clear:
- Issues → Execute work
- Projects → Deliver outcomes
- Initiatives → Drive strategy

Initiatives exist to ensure execution ladders up to business impact. Without disciplined Initiatives, execution becomes busy but unfocused.

## Q&A

**Q: Can an Initiative exist without Projects?**
No. Initiatives must be executed through Projects. If there are no active Projects, the Initiative is not active.

**Q: Who owns an Initiative?**
Each Initiative must have exactly one accountable owner. The owner is responsible for: strategic clarity, alignment across Projects, metric tracking, status accuracy, escalation when risk appears.

**Q: What if the metric isn't moving?**
If execution is happening but the metric is not improving: reassess strategy, reassess assumptions, reassess project mix. Activity does not equal impact.
